## طريقة بناء ملف APK بدون تثبيت برامج (عبر GitHub Actions)
1. أنشئ مستودعاً جديداً على GitHub وارفَع جميع ملفات هذا المشروع إليه.
2. افتح تبويب **Actions** داخل المستودع ثم اختر **Build Noor Tilawa APK**.
3. اضغط **Run workflow** (أو انتظر انتهاء البناء التلقائي بعد الرفع).
4. بعد نحو دقيقتين ستجد ملف `noor-tilawa-debug-apk` في قسم **Artifacts** بالأسفل — حمّله وفك الضغط لتحصل على `app-debug.apk` وثبّته على هاتفك مباشرة.

## طريقة البناء محلياً (Android Studio)
1. افتح هذا المجلد في **Android Studio**.
2. انتظر اكتمال مزامنة Gradle.
3. من القائمة العلوية اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
